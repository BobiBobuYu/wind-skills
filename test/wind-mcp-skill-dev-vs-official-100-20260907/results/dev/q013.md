**三、分歧来源拆解**

1. **收入端分歧较小、随时间小幅放大**：2026年5家营收预测极差仅0.83%（827.3B~834.2B），2027年扩大到5.1%（899.4B~945.1B），2028年进一步扩大到8.7%（975.1B~1060.2B）。短期收入判断高度一致，长期分歧主要体现在游戏流水、广告变现和企业服务/云增速的外推斜率上，但整体幅度在五个维度中最小。

2. **利润率端分歧明显大于收入端**：2026年净利润极差约3.0%，2027年扩大到13.8%（238.4B~271.2B），2028年为13.6%（256.5B~291.2B）。折算隐含净利率后可见，第一上海系统性高于其余4家（28.3%~29.5% vs 其余25.9%~27.9%），且这一差距在2027-2028年持续存在。也就是说，在收入假设彼此接近的前提下，净利润预测的分歧主要来自对成本费用率/净利率演化路径的不同假设，是比收入更大的分歧来源。

3. **资本开支：各家方向一致，但转化节奏假设不同**：`stock_get_company_finance_analysis`显示，腾讯资本性支出从2024年960.48亿元增至2025年1128.75亿元，2026年上半年已达1071.63亿元（接近去年全年水平），主要投向AI算力与数据中心，与`stock_get_company_updates`中披露的"2026H1资本开支847亿元、主要用于算力与数据中心建设"相互印证。研报观点（如天风证券"金股"逻辑）明确把"云业务利润率能否回升至22%""AI商业化能否有效转化为收入"列为2026年净利润能否实现同比+18%的核心变量；`stock_get_company_updates`中的风险提示也直接指出"AI资本投入无法有效转化为收入，拖累利润率表现"是主要风险之一。由此看，各机构对腾讯"要不要加大AI capex"没有分歧，分歧在于这笔支出"多快、以多大比例"转化为收入和利润——这正是上一条净利率分歧的根源，而非收入或capex规模本身的分歧。

4. **估值端分歧幅度最大，且与盈利预测的乐观/保守程度不完全对应**：5家目标价从520.23港元（东方证券）到733港元（第一上海），极差41%，是各维度中分歧最大的一项。但值得注意，东方证券对2027、2028年的营收预测（945071、1060185百万元）在5家中均为最高，净利润预测（253560、287378百万元）也居第2位，基本面判断并不悲观，却给出全组最低目标价；反观第一上海营收假设与同业接近，主要靠更高的净利率假设及更高的目标估值倍数，得出全组最高目标价。结合`stock_get_company_valuation`数据，腾讯当前PE(TTM)14.72倍，处于3年分位19.18%、5年分位27.65%的历史低位，而可比公司（Meta、网易、谷歌-C、亚马逊、小米集团-W等）2026年预测PE均值14.74倍、中位数19.4倍——说明市场对"腾讯估值是否应向可比公司中枢修复"本身存在分歧，这是最终目标价分歧的主要独立来源，其影响甚至超过盈利预测本身的分歧。

**四、结论**

- 分歧幅度由小到大排序大致为：收入 < 净利润(利润率) ≈ 资本开支(转化节奏) < 估值(目标价)。
- 收入预测本身分歧有限，卖方在短期（2026年）高度收敛，中长期（2027-2028年）因AI/云/广告变现节奏判断不同才逐步拉开，但幅度可控（5%~9%）。
- 利润率是盈利预测层面分歧的主要来源：在收入假设接近的情况下，各家对AI资本开支"何时、以多快速度"转化为收入和利润率改善的判断不同，直接体现为隐含净利率3~14个百分点的差异；这一分歧的根源正是资本开支的转化节奏假设，而非资本开支规模本身（各家一致认可腾讯将持续加码AI capex）。
- 目标价（估值倍数）层面的分歧最大（41%），且与基本面预测的乐观/保守程度不完全一致（东方证券基本面预测最高但目标价最低），说明估值倍数假设——即是否给予AI资本开支带来的长期确定性溢价、是否向海外可比公司估值中枢修复——是导致最终目标价分歧的关键变量，甚至比盈利预测本身的分歧影响更大。
